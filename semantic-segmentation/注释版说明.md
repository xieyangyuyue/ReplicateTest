# awesome-semantic-segmentation-pytorch 中文注释版说明

本仓库克隆自 [Tramac/awesome-semantic-segmentation-pytorch](https://github.com/Tramac/awesome-semantic-segmentation-pytorch)，
在**不改变任何代码逻辑**的前提下，为全部代码添加了中文注释（逐行注释版）。

## 一、注释范围与统计

| 项目 | 数量 |
| --- | --- |
| Python 文件 | 70 个（含 3 个空 `__init__.py`） |
| 原始代码行数 | 9,819 行 |
| 注释后总行数 | 12,074 行 |
| 纯注释行（整行 `#`） | 2,540 行 |
| 另有行尾注释 | 数千处（未单独统计） |
| 其他注释文件 | `scripts/*.sh`（2 个）、`requirements.txt`、`docs/requirements.yml` |

## 二、注释规范

1. **每个文件头部**：中文注释块说明文件职责、模型核心思想、论文名称、在工程中的位置。
2. **每一行代码**都有注释：行尾 `# 中文注释`，或紧邻上方的注释行（函数参数说明、多行 docstring 起始行的说明等）。
3. 原有英文 docstring、英文注释**全部原样保留**（docstring 是字符串内容，行尾加注释会改变其值，故改用上方注释行说明）。
4. forward 中的张量形状变化全程标注（如 `(N, 2048, H/8, W/8) → (N, nclass, H, W)`）。
5. 发现的原代码问题以**【注意】**标出，代码保持原样不修复。

## 三、机器校验（全部通过）

| 校验项 | 方法 | 结果 |
| --- | --- | --- |
| 语法 | `compile()` 全量编译 70 个文件 | 70/70 通过 |
| 注释覆盖率 | tokenize 级逐行检查：每行代码有行尾注释或紧邻上方注释 | 70/70 全覆盖 |
| **代码零改动** | 注释版与原始副本的**代码 token 流**（剔除 COMMENT/NL）逐 token 比对 | 70/70 完全一致 |

两处说明（唯一的"非注释"文本变化，均不影响代码 token 流）：
- 9 个原文件"末尾无换行符"，注释时补齐了 EOF 换行（token 级等价）；
- 2 处反斜杠续行的中间行（`downloader/mscoco.py`、`encnet.py` 的 `Encoding.__repr__`）因 Python 语法禁止在 `\` 续行之间插注释，采用了"合并物理行"方案——`\`+换行本身不产生 token，合并后 token 流与原版完全一致。

## 五、注释过程中发现的原代码问题清单

以下问题**均未修复**（保持原样），已在对应行的注释中以【注意】详细标出。按严重程度分类：

### A. 严重 bug（触发即报错或功能失效）

| 位置 | 问题 |
| --- | --- |
| `scripts/demo.py` L19 | `choices=['pascal_voc, pascal_aug, ade20k, citys']` 把整个列表写成一个字符串，任何合法数据集名都会被判为 invalid choice |
| `scripts/train.py` L164 | `assert ext == '.pkl' or '.pth'` 运算符优先级错误，恒为真，任意扩展名都能通过 |
| `core/models/model_zoo.py` L43 | 注册表键 `'danet_resnet50_ciyts'` 拼错（应为 citys），按正确名查找会 ValueError |
| `core/models/model_store.py` L37 | `.format()` 只作用于第二个字符串字面量，报错信息中不出现文件名 |
| `core/models/psanet.py` L130 | `get_psanet` 加载预训练权重的前缀误写为 `'deeplabv3_'`（复制粘贴错误） |
| `core/models/deeplabv3_plus.py` L100 | `_ASPP(...)` 调用缺少必填的 `norm_kwargs` 参数，构造即 TypeError |
| `core/models/base_models/hrnet.py` L206/215/353 | stage3/4 过渡层被重复赋给 `self.transition1`（应为 transition2/3）→ forward 时 AttributeError；`F` 未导入 → `__main__` 自测必崩 |
| `core/nn/basic.py` L74/80 | `self.avgpool.append(...)` 属性名少写 s；`for (a, c) in enumerate(zip(...))` 解包错误 → `_PSPModule` 构造即崩（注：实际使用的是 espnet.py 中的另一份实现，此文件版本为废弃遗留） |
| `core/utils/lr_scheduler.py` L133/179 | `elif self.warmup_factor == 'linear'` 应为 `warmup_method`（线性 warmup 永不生效）；`__main__` 中 `WarmupPolyLR(niters=1000)` 无此形参（应为 max_iters） |
| `core/data/downloader/pascal_voc.py` L116 | `not os.path.isfile(path)` 应为 `os.path.isdir`：目录已存在也会恒进入下载分支 |
| `core/data/dataloader/mscoco.py` L88/97 | `os.path.basename(整数)` 必抛 TypeError；`instance['Segmentation']` 大写键名与 COCO 官方小写不符 |
| 全部模型工厂函数 | `torch.device(kwargs['local_rank'])`：不传 local_rank 即 KeyError；传 int 时行为依赖 PyTorch 版本（应为 `torch.device('cuda', rank)`） |
| `core/models/hrnet.py` | 空壳占位：`__init__` 无任何层、`forward` 为 `pass`，且未注册进 model_zoo |
| `core/models/swnet.py` | 文件名与内容不符：实为 ENet 的加深变体（类名 ENet、函数 get_enet），与 enet.py 的 `__all__` 同名冲突 |

### B. 废弃 API（新版环境运行风险）

- `torch.utils.model_zoo.load_url` → 建议 `torch.hub.load_state_dict_from_url`（骨干网络加载，多处）
- `torch.autograd.Variable`、`tensor.data` → 建议 `tensor.detach()`（tests、loss.py 等）
- `torch.ByteStorage.from_buffer`（distributed.py）→ PyTorch 2.x 已移除
- `from pip import main` / `pip._internal`（filesystem.py）→ pip≥10 已失效，自动安装链路不可用
- `nose.runmodule()`（test_module.py）→ nose 已停止维护，Python 3.10+ 无法导入
- `from six.moves import urllib`（dataloader/utils.py）→ six 停止维护
- `from torch.utils.model_zoo import tqdm`（dataloader/utils.py）→ 新版 torch 已移除
- `nn.Dropout2d`（cgnet.py 等）→ PyTorch≥1.11 弃用
- `1 - valid_mask`（loss.py）→ bool 张量减法新版报错，应为 `~valid_mask`
- `torch.load` 未指定 `map_location` / `weights_only`（全部模型工厂）→ PyTorch≥2.6 行为变更

### C. 可疑写法 / 逻辑问题（精选）

- `train.py`：`--use-ohem type=bool` argparse 经典误用（传 `--use-ohem False` 也为 True）；`epochs/lr` 按数据集自动配置的分支永不触发（死代码）；resume 仅恢复权重不恢复优化器；验证集为空时 `pixAcc/mIoU` 未定义即被使用；学习率按 GPU 数线性放大
- `psanet.py`：注意力输出通道硬编码 3600，仅支持 480×480 输入
- `resnet.py` vs `resnetv1b.py` vs `resnext.py`：`dilated` 参数默认值互相矛盾，易误用
- `xception.py`：Xception71 的 block2 双重 stride=2 下采样，实际输出步长是参数值的一半
- `eespnet.py`：level5 堆叠用 `reps[2]`（=7）疑应为 `reps[3]`（=3）；`while True` 池化循环在特殊奇偶尺寸下有死循环风险
- `enet.py`：`bottleneck3_5` 已定义但 forward 从未调用（权重不匹配隐患）
- `icnet.py`：`jpu` 参数未透传给基类（传 True 无效）；`pyramids=[1,2,3,6]` 可变默认参数
- `dataloader/pascal_aug.py`：训练集读 trainval.txt（SBD 全量），在 VOC val 上评估存在训练/验证重叠风险
- `downloader/cityscapes.py`：完全没有下载逻辑（URL 列表存的是本地文件名）；description 误写 ADE20K
- `visualize.py`：`get_color_pallete` pascal 分支就地修改传入数组（调用方数据被污染）
- `model_zoo.py`：`get_segmentation_model` 未知名直接裸 KeyError；`get_model_list()` 返回视图非副本
- `distributed.py`：`dist.reduce(dst=0)` 仅 rank0 得到归约值（其余 rank 拿到本地未平均值）
- `parallel.py`：依赖 `torch.nn.parallel._functions` 等私有 API

### D. 文档 / 拼写问题（示例）

- `deeplabv3.py`、`danet.py` 的模块 docstring 误写为 "Pyramid Scene Parsing Network"（复制粘贴遗留）
- `swnet.py` 原注释 `#blcok 2:`；`bisenet.py` 类名 `AttentionRefinmentModule`；`enet.py` 属性 `downsamping`；`model_store.py` `'trainning'`；`loss.py` `"Lables"` 等
- `train.py` 多处 argparse help 中的默认值与实际 default 不符

> 完整明细（含行号）见各文件内【注意】注释。

## 六、运行方式（与原仓库一致）

```bash
# 1. 安装依赖（建议按注释中标注的新版 API 自行调整版本）
pip install -r requirements.txt

# 2. 准备数据集（以 PASCAL VOC 为例），可用 core/data/downloader/ 下的脚本（注意上文列出的已知问题）
python -m core.data.downloader.pascal_voc

# 3. 训练
cd scripts
bash fcn32s_vgg16_pascal_voc.sh          # 或直接 python train.py --model fcn32s --backbone vgg16 --dataset pascal_voc

# 4. 评估 / 推理
python eval.py --model fcn32s --dataset pascal_voc ...
python demo.py --model fcn32s_vgg16_voc --input-pic <图片路径>
```

> 注：该仓库基于 2019 年前后的 PyTorch（>=1.1）生态。在新版 PyTorch/pandas/scipy 上运行
> 需按各文件【注意】注释替换废弃 API；模型结构本身无需改动。
